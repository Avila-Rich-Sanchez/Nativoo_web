# Recursos de marca

Coloca aquí el logo proporcionado como `logo-nativo.png`. La landing lo usa en la navegación, el hero y el pie de página, y conserva un monograma de texto mientras el archivo no esté disponible.

Las fotos actuales del menú y del hero son imágenes remotas de demostración. Para producción, usa imágenes WebP optimizadas y actualiza sus URL en `index.html`, `js/menu.js` y `supabase/seed.sql`.
